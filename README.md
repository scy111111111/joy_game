# AI扫雷对战游戏

一个有趣的三人AI扫雷对战游戏，由京东、美团和饿了么三个AI玩家轮流进行扫雷对决。游戏采用经典Windows扫雷风格，并针对移动设备进行了UI优化。

![游戏截图](https://i.imgur.com/example.png)

## 游戏特点

- **三个AI玩家对战**：京东、美团和饿了么三个AI玩家轮流扫雷
- **预测胜利者**：玩家可以在游戏开始前预测哪个AI会获胜
- **历史战绩记录**：记录游戏结果和预测准确率
- **响应式设计**：适配手机和桌面设备
- **Windows经典风格**：采用Windows 98风格的界面设计
- **动态头像**：三个AI玩家使用生动的GIF动画头像
- **音效系统**：各种游戏操作都有对应的音效反馈
- **难度选择**：支持初级、中级和高级三种难度级别

## 难度级别

- **初级**：8×8 棋盘，10个地雷，浅绿色背景，AI更倾向于安全选择
- **中级**：16×16 棋盘，40个地雷，浅蓝色背景，AI采用平衡策略
- **高级**：16×30 棋盘，99个地雷，浅红色背景，AI更倾向于冒险

## 如何运行

### 开发环境

1. 克隆仓库或下载源代码
2. 安装依赖：
   ```bash
   npm install
   ```
3. 启动开发服务器：
   ```bash
   npm run dev
   ```
4. 在浏览器中访问：`http://localhost:5173`

### 生产环境

1. 构建生产版本：
   ```bash
   npm run build
   ```
2. 使用静态文件服务器提供dist目录：
   ```bash
   npx serve -s dist
   ```
3. 在浏览器中访问：`http://localhost:3000`

更多部署选项，请参阅 [DEPLOY.md](./DEPLOY.md)。

## 技术栈

- **前端框架**：React + TypeScript
- **构建工具**：Vite
- **状态管理**：React Hooks (useState, useEffect, useCallback)
- **样式**：CSS3 (动画、Flexbox布局)
- **存储**：LocalStorage (保存历史战绩)
- **音效**：Web Audio API

## 游戏玩法

1. 游戏开始时，选择预测哪个AI玩家会获胜
2. 选择游戏难度（初级、中级或高级）
3. AI玩家轮流自动翻开格子
4. 如果翻开的格子是安全的，该AI获得分数
5. 如果翻开的格子是地雷，该AI被淘汰
6. 当所有安全格子被翻开或只剩一个活跃玩家时，游戏结束
7. 得分最高的玩家获胜
8. 游戏结果记录到历史战绩中
